# Hoofdstuk Vue - Opdracht 15

Doel: een custom store implementeren.

Deze versie bevat:

- centrale state in `store.js`
- getter `getAllGroceries`
- getter `getGroceryById`
- action `addGrocery`
- action `updateGrocery`
- action `removeGrocery`
- formuliercomponent `GroceryForm.vue`
- create/edit/delete functionaliteit

## Starten

```powershell
npm install
npm run dev
```

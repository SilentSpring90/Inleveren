# Hoofdstuk Vue - Opdracht 12

Doel: de boodschappenlijst opsplitsen in een component.

Belangrijk:

- `App.vue` heeft de producten-array.
- `GroceriesTable.vue` ontvangt de producten via props.
- De tabel en totalen staan in `GroceriesTable.vue`.

## Starten

```powershell
npm install
npm run dev
```

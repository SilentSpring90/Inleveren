# Hoofdstuk Vue - Opdracht 11

Doel: een eerste Vue 3/Vite boodschappenlijst maken.

In deze versie staat alles in `src/App.vue`:

- producten array in `<script setup>`
- `v-for` om producten te tonen
- `v-model.number` om aantallen aan te passen
- `computed` om het totaalbedrag automatisch te berekenen

## Starten

```powershell
npm install
npm run dev
```
